Управление кластером

На сервере кластера запустите контейнер с выбранным именем. Для каждого нового воркера укажите отдельное имя:

cd /project
bash scripts/start-worker.sh --name worker-4

После готовности контейнера добавьте его по тому же имени и запустите балансировку.

Зарегистрированные узлы

Активность указана по метаданным Citus и не подтверждает сетевую доступность узла.

Чтобы вывести воркер, нажмите «Освободить» в его строке. Страница дождётся переноса шардов на другие воркеры. Затем нажмите «Удалить из кластера». Если перенос завершился с ошибкой, освобождение можно повторить.

Удаление доступно после освобождения; сервер проверяет отсутствие распределённых шардов. Контейнер и его том остаются на сервере. Остановить контейнер можно после удаления узла из кластера.
