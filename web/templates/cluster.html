Управление кластером

Перед добавлением worker-3 запустите его контейнер в Ubuntu:

cd /project
docker compose --profile scale up -d --wait worker-3

Для вывода worker-3 сначала перенесите его распределённые шарды. Команда ниже выполняется в Ubuntu и ожидает окончания переноса:

cd /project
docker compose exec -T coordinator psql -U postgres -d coursework -v ON_ERROR_STOP=1 < sql/cluster/drain_worker.sql

Перед удалением сервер проверяет отсутствие распределённых шардов. Оставшиеся копии справочников удаляет Citus. Контейнер можно остановить после исключения узла:

docker compose stop worker-3
